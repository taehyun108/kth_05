# 00 — 개요 및 요구사항 대조

## 착수 요약

> 이 문서는 **13회 검증**을 거친 확정본이다. 처음 여는 사람은 이 절 → §0.5 추적표 → §15 퀵스타트 → §10 로드맵 순으로 보면 된다.

### 무엇을 만드는가

포스코 그룹·이차전지 산업·정책·법령·통상 뉴스를 **자동 수집 → 요약 → 포스코퓨처엠 기준 영향도·SWOT 분석 → 다채널 배포**하는 시스템. 사람은 **질문만** 한다.

### 4개 트랙

| | 대상 | 웹 탭 | 카톡 | 메일 |
|---|---|---|---|---|
| **T1 포스코** | 그룹 7개 계열사 | `/posco/` | ✅ | Part A |
| **T2 이차전지 산업** | 국내외 셀·소재·원료사 | `/posco/` | 포스코 언급 시 | Part A/B |
| **T3 정책·법령** | 지원제도·행정예고·시장전망 | `/policy/` | 포스코 언급 시 | Part B |
| **T4 통상·규제** | 관세·수출통제·무역구제 | `/trade/` | 포스코 언급 시 | Part B |

### 핵심 설계 결정 8가지

| # | 결정 | 이유 |
|---|---|---|
| 1 | **카톡 발송 기준은 트랙이 아니라 `posco_relevance`** | 통상 기사여도 포스코퓨처엠이 언급되면 보낸다 (§1.3) |
| 2 | **SWOT 기준점은 항상 포스코퓨처엠** | 경쟁사·정책 기사도 "우리에게 무엇인가"로 해석 (INV-2) |
| 3 | **SWOT은 웹에서만** — 카톡·메일·텔레그램에 절대 미포함 | 발송 코드가 SWOT 파일을 import조차 하지 않음 (INV-3) |
| 4 | **LLM은 소량·고가치에만** — 대량 요약은 규칙+로컬 | Groq 무료 티어로는 물량 미달. API 키 없이 $0 구성 (§11.6) |
| 5 | **07:00은 만드는 시각이 아니라 보내는 시각** | 전일 기사는 자정에 확정 → 야간 배치 (§6.4) |
| 6 | **인증은 서버에서** — 데이터는 `/api/` 뒤 | 정적 사이트의 가짜 잠금 문제 해소 (INV-8) |
| 7 | **`crisis` 논조는 자동 발송 금지** | 홍보실 방침이 먼저 정해져야 하는 사안 (§4.7.5) |
| 8 | **카톡 출력 포맷 🔒고정** — 링크 카드 + `[매체명]` 요약 2메시지 | 형태가 깨질 바에는 미발송. 코드로 강제 (INV-10, §4.7.3) |

### 실행 환경

```
Z2 외부망 PC   파이프라인 실행 (Ollama·Claude Code) + 메일 발송 + git push
Vercel         웹 서빙 + 로그인(3단 레벨) + 챗봇 API
GitHub Actions 스케줄·수집·발송
Z3 모바일      카톡 수신 · 웹 열람(SWOT 포함)
```
