### F-09. Q&A 챗봇

**동작 (RAG)**

```
질문 → ① 슬롯 추출(트랙/회사/국가/기간/논조/토픽, JSON 강제)
     → ② 검색: facets 필터 + BM25/임베딩 스코어 → 상위 8건
            (웹 인증 세션이면 issues.json 도 검색 대상)
     → ③ Claude 답변 생성 (후보 요약만 전달, 본문 전문 미전달)
     → ④ 출처 각주(기사 id + 링크) 포함 반환
```

#### 4.9.5 법령 검색 기능 (v2.0 신규 — 요구사항 D2)

챗봇의 법령 질의는 **아카이브 RAG만으로는 답할 수 없다.** 수집된 기사에 없는 조문을 물어볼 수 있기 때문이다.

```
"폐기물관리법 배터리 재활용 조항"
  ↓
① 아카이브 검색 — laws.json에 해당 법령이 있는가
  ├─ 있음 → 엔티티 + 타임라인 + 당사 영향(L2) 반환
  └─ 없음 ↓
② 국가법령정보센터 API 실시간 조회 — 법령명·조문 검색
  ↓
③ 조문 원문 + 요약 반환 (조문은 공공저작물이라 인용 가능)
  ↓
④ L2 세션이면 "당사 영향" 분석을 덧붙임 (L2, on-demand)
```

**중요한 경계**

| 하는 것 | 하지 않는 것 |
|---|---|
| 조문 위치·내용 안내 | **법률 자문** |
| 시행일·예고기간 안내 | 위법 여부 판단 |
| 당사 사업과의 관련성 정리 | 법적 리스크 확정 진술 |

> 답변 하단에 **"법률 자문이 아니며 정확한 해석은 법무 부서·법률전문가 확인이 필요합니다"** 를 고정 표기한다. 법령은 조문 하나로 의무가 갈리는 영역이라 이 경계가 특히 중요하다.

**할루시네이션 방지 (시스템 프롬프트)**

- 아카이브에 근거가 없으면 추측 금지 → "수집된 기사에 없습니다"
- 모든 사실 주장에 기사 id/링크 각주
- 수치는 기사에 있는 것만 인용, 계산·추정 시 명시
- **메신저 채널에서는 SWOT·시사점·정책건의 문구 출력 금지** (프롬프트 + 후처리 필터 이중 차단)
- 정책 해석은 "법률 자문이 아님" 고지
